## 环境要求
- **操作系统**: Windows 10/11 或 macOS 10.15+
- **必要软件**: 
  - Python 3.6+ (用于启动本地服务器)
  - 现代浏览器 (Chrome 80+, Firefox 75+, Edge 80+)

## 安装步骤

### 1. 下载并解压部署包
1. 下载网站部署包 `tcm-doctor-website.zip`
2. 将压缩包解压到您选择的文件夹 (例如: `C:\tcm-website` 或 `~/tcm-website`)

### 2. 安装Python (如未安装)
- **Windows**:
  1. 访问 https://www.python.org/downloads/ 下载Python 3.6+
  2. 安装时勾选 "Add Python to PATH" 选项
  3. 完成安装后，打开命令提示符，输入 `python --version` 验证安装成功

- **macOS**:
  1. macOS通常预装Python，打开终端输入 `python3 --version` 检查版本
  2. 如未安装或版本过低，使用Homebrew安装: `brew install python3`

## 启动方法

### Windows系统
1. 双击运行解压文件夹中的 `start_windows.bat` 文件
2. 系统将自动启动本地服务器并打开浏览器访问网站

### Mac系统
1. 打开终端，导航到解压文件夹: `cd /path/to/tcm-website`
2. 运行命令: `chmod +x start_mac.sh` (仅首次运行需要)
3. 双击运行 `start_mac.sh` 文件或在终端输入: `./start_mac.sh`
4. 系统将自动启动本地服务器并打开浏览器访问网站

## 故障排除

### 端口被占用
- **问题**: 提示 "Address already in use" 或 "端口已被占用"
- **解决**: 
  1. 关闭占用端口的程序
  2. 或修改启动脚本中的端口号:
     - Windows: 编辑 `start_windows.bat` 文件，修改 `8000` 为其他数字 (如 `8080`)
     - Mac: 编辑 `start_mac.sh` 文件，修改 `8000` 为其他数字 (如 `8080`)

### 浏览器未自动打开
- **问题**: 服务器启动成功但浏览器未自动打开
- **解决**: 手动打开浏览器，访问 http://localhost:8000 (或您修改的端口号)

### Python未找到
- **问题**: 提示 "python不是内部或外部命令"
- **解决**: 
  1. 确保Python已安装并添加到系统PATH
  2. 或在启动脚本中使用完整Python路径，如: `"C:\Program Files\Python39\python.exe" -m http.server 8000`

## 常见问题

### Q: 本地部署是否包含所有功能?
A: 是的，本地部署包含网站的全部功能，使用模拟数据运行，无需连接互联网。

### Q: 数据是否会保存在本地?
A: 是的，预约信息等数据会保存在浏览器的localStorage中，刷新页面后不会丢失。

### Q: 是否需要互联网连接?
A: 不需要，所有资源已包含在部署包中，可完全离线运行。

### Q: 如何更新网站内容?
A: 本地部署版本不支持在线更新，如需更新内容，请下载最新部署包并重新部署。
